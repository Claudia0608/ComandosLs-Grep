# COMANDOS LS Y GREP

ESTE PROYECTO PERMITE EJECUTAR COMANDOS DEL SISTEMA OPERATIVO LINUX DESDE JAVA, UTILIZANDO `LS` PARA LISTAR ARCHIVOS DE UN DIRECTORIO Y `GREP` PARA FILTRAR RESULTADOS Y DEVOLVER AQUELLO QUE CONTENGA UNA "A".

---

## FUNCIONAMIENTO GENERAL

1. LA APLICACIÓN RECIBE UNA RUTA COMO ARGUMENTO. SI NO SE PROPORCIONA, USA UNA RUTA POR DEFECTO.
2. SE EJECUTA EL COMANDO `LS` EN ESA RUTA PARA OBTENER LA LISTA DE ARCHIVOS.
3. ESA LISTA SE PASA AL COMANDO `GREP`, QUE FILTRA LAS LÍNEAS QUE CONTIENEN UNA LETRA A.
4. EL RESULTADO FILTRADO SE MUESTRA EN CONSOLA.

---

## DESCRIPCIÓN DE LAS CLASES

### `EJECUTARCOMANDO`

- RECIBE LA RUTA COMO ARGUMENTO O USA UNA POR DEFECTO.
- CREA INSTANCIAS DE LAS CLASES `COMANDOLS` Y `COMANDOGREP`.
- EJECUTA `LS` Y LUEGO FILTRA LA SALIDA CON `GREP`.
- MUESTRA EL RESULTADO EN CONSOLA.

### `COMANDOLS`

- EJECUTA EL COMANDO `LS` EN LA RUTA INDICADA.
- LEE LA SALIDA DEL COMANDO Y LA DEVUELVE COMO TEXTO.
- UTILIZA `PROCESS`, `BUFFEREDREADER` Y `STRINGBUILDER`.

### `COMANDOGREP`

- EJECUTA EL COMANDO `GREP` CON UN PATRÓN DE FILTRADO.
- ESCRIBE EL TEXTO A FILTRAR EN LA ENTRADA DEL PROCESO.
- LEE LA SALIDA FILTRADA Y LA DEVUELVE COMO TEXTO.
